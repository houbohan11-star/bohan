# 开发验收顺序

| 阶段 | 验收标准 |
| --- | --- |
| 当前骨架 | doctor；有音频/无音频视频提取；失败 manifest；批量失败继续；非法参数和目录覆盖拒绝 |
| 下载与恢复 | 真实用户链接单任务下载；来源哈希；参数或模型版本改变不误复用；重试不混入其他商品 |
| Whisper | 德语实测样本、原文与时间段落核对；没有音轨时跳过；离线缓存缺失明确失败 |
| Qwen3-VL | 真实样本逐条对应证据；遮挡、低清和推测明确标注；硬件资源实测 |
| 导演脚本 | 当前商品独立白名单；德语中文对照、钩子、完整动作与试配音计时；用户确认记录 |
| 九宫格与生成 | 独立关键帧逐格质检；人物/商品/场景连续；第二段首格对应实际生成尾帧 |
| 批量生产 | 每阶段恢复测试、资源限额、错误分类、生成成本控制和小批量回归 |

不为了完成率伪造转写、镜头或商品信息。模型输出与证据、推测、复核结论分别保留。模型加载与集成测试必须在目标设备上另行验收。
