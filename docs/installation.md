# 依赖与安装顺序

## 已实现并可验收的最小环境

| 顺序 | 组件 | 用途/状态 |
| --- | --- | --- |
| 1 | Python >=3.11 + venv | 标准库运行时；当前验收 Python 3.12 |
| 2 | FFmpeg + ffprobe | 操作系统依赖；doctor 验证是否在 PATH |
| 3 | setuptools >=68 | 构建元数据依赖；不参与模型推理 |
| 4 | `pip install -e .` | 安装本地 bohan-video，无第三方运行依赖 |
| 5 | unittest + 合成视频 | 不联网、不下载权重的基础验收 |

当前没有经过完整模型验收的依赖锁文件，不能宣称 pip 安装完全可复现。首次发布模型后端时应记录硬件、精确依赖锁、权重版本和样本结果。不要因导入包而自动安装软件或下载权重。

## 接下来逐项接入（尚未安装或验证）

1. **单链接下载**：评估 yt-dlp 适配器，下载与离线分析分进程；锁定版本、校验失败分类与输出路径后再列入可选依赖。
2. **ASR**：选择并验收一个 Whisper 实现（候选 faster-whisper），先 CPU 德语短片；确定模型大小、离线缓存与时间戳行为。GPU/CUDA 环境单独评估，不默认可用。
3. **画面模型**：确定 Qwen3-VL 的具体权重规模与许可证，测量内存/显存，再根据官方模型说明验证 PyTorch、Transformers、视觉预处理依赖。避免先锁定未经硬件验证的版本组合。
4. **扩展**：切镜、OCR、WhisperX 强制对齐只有在真实业务样本证明需要后分别安装、验收。

模型适配器应预先下载公开权重，分析阶段优先使用离线环境。v0.1 本身不提供操作系统级网络隔离；不得因此宣称已实现隔离。外部权重与个人视频不提交到 Git。
